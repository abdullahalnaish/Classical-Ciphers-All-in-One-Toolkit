# Classical-Ciphers-All-in-One-Toolkit
This is toolkit that combines multiple classic cryptography algorithms in one project.

## Features
- Multiple classical ciphers.
- Encryption & decryption.
- Simple interface.
- Educational purpose.

## Supported Ciphers
- Caesar
- Vigenère
- Hill
- Rail Fence
- Affine
- ROT13

## Requirements
- Python 3.x
